# Demo CSV наборы

Загружать в порядке: `cost_centers.csv`, `items.csv`, затем `plan.csv` и `fact.csv` из нужного сценария.

- `base/` — справочники ЦФО и статей.
- `c1_ideal/` — план и факт совпадают.
- `c2_overspend/` — есть перерасход выше порога 10%.
- `c3_mixed/` — смешанный сценарий: норма, экономия, перерасход, нет плана.
- `c4_invalid/` — набор для проверки ошибок: неверный период, неизвестные ссылки, отрицательная сумма, дубль.
- `c5_large_timeseries/` — самый плотный набор для визуализаций: 15 ЦФО, 25 статей, 24 месяца. Загружайте все 4 файла из этой папки, чтобы график и heatmap были максимально заполнены.

Файл `проектная_деятельность.dt` в корне — дамп 1С. Для веб-MVP он хранится как исходный артефакт; приложение принимает CSV-выгрузки, которые можно получить из 1С.
